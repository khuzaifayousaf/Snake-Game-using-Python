# Snake-Game-using-Python
This is a classic 2D Snake game built in Python with the pygame library.
You control a snake that moves around a grid, eating red food to grow longer and score points.
Each food item gives 10 points, and the game gradually speeds up as your score increases.
The game ends if the snake hits a wall or runs into its own body.
You can steer with the arrow keys or WASD, pause with P, and restart with R or Space.
A score bar at the top shows your current score and your best score for the session.
The code is organized into a Snake class and small helper functions, so it’s easy to read and modify.
You can change the grid size, colors, and speed from the settings at the top of the file.
